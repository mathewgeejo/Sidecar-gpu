PROTOCOL / THREE STEPS

The execution contract

HOW SIDECAR WORKS
01

Send the inputs

Your client uploads matrices or images. Identical files can be reused without sending their payload again.

02

Let the worker execute

The worker accepts a durable job and executes it on its configured CPU or NVIDIA CUDA device.

03

Bring back the result

Reconnect by job ID, inspect actual timings, and download a result whose hash can be verified.

The device matters. A CPU worker uses its CPU. GPU offloading requires a CUDA worker. Running both sides on one PC tests the workflow and connection; this dashboard does not establish physical separation.
